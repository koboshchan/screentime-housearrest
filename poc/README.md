# Private proof of concept

The complete pre-restructure implementation is preserved locally under `private/`. This archive is intentionally ignored by Git and has owner-only permissions. It contains experimental remote scripts, personal database snapshots and captures, and embedded credentials. It is research material, not a runtime dependency or supported command-line interface.

The unmodified whole-folder backups outside this repository remain the recovery source. The newer backup was verified before restructuring, including hidden files, untracked content and Git metadata.

Only newly written, reviewed platform sources may be committed. Never remove the `poc/private/` ignore rule or add this archive to a package.
